# v0.3：待核验结果保留与全文药物规则

## 保留约定

所有自动抽取默认使用 `verification: pending`，并提供 `confidence`、`confidence_basis` 和核验原因。评分是 0～1 的规则启发式分数，未经概率校准，不是医学正确率，也不会因分数高就变成人工已核验结果。

不确定、部分命中、缺原文锚点或缺图谱端点的提议都保留完整内容，不能只留下一个被丢弃的 ID。当前存储位置如下：

| 集合 | 内容 |
|---|---|
| nodes / edges | 已能结构化的实体及关系，仍标记待核验 |
| thresholds | 可按明确主题结构化的随访间隔，仍待核验 |
| threshold_candidates | 三份全文中匹配数值模式的所有候选，不再因标题未识别而省略 |
| edge_candidates | 部分命中的旧规则提议，以及缺端点、缺证据的完整关系记录 |
| entity_candidates | 与最长匹配重叠的词表候选，保留位置和原文 |
| extraction_candidates | 未完整解析的药物语句、表格片段、数值提及、缺代号定义的方案候选 |
| blocks | 原始证据块及页码、章节、原文；未知章节不伪造 |

`discarded` 仅保留空数组用于旧格式兼容。规则根本没有触发不意味着已经抽取了一条关系；本轮额外保留药物相关原句，供后续扩展规则时核读。

每次 CLI 重建若内容发生变化，覆盖图谱前会将完整旧文件保存到 `<输出名>.history/<SHA256>.json`，包括旧候选和旧原文块。新图谱的 `meta.history_snapshots` 记录路径和校验值。内容未变时不重复生成快照。该机制从本版本开始工作，未宣称能够恢复启用前已被覆盖的文件。

## 联合方案和条件

基层指南原文定义 A 为 ACEI 或 ARB、B 为 β 受体阻滞剂。`A+B` 保存为 DrugRegimen：

```json
{
  "selection": "all_components",
  "components": [
    {"code": "A", "options": ["ACEI", "ARB"], "selection": "one_of"},
    {"code": "B", "options": ["β受体阻滞剂"], "selection": "one_of"}
  ]
}
```

实际图谱使用规范中文名。A 组成部分的两个选项不会被解释为同时使用。缺少本文件的代号定义证据时，方案保留为 unresolved 候选，不补猜定义。

临床关系保留 condition、scope、modality、choice_group、exceptions 及必要的 supporting_evidence。噻嗪类利尿剂的痛风禁忌不扩展成所有利尿剂禁用；ARNI 与 ARB 联用限制中的“相同成分的 ARB 除外”保留在 exceptions。
