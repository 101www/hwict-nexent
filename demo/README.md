# 可视化 Demo 页面

## 必须展示的三件事（对应评委关注点）
1. **多跳推理过程可见**：逐步展开推理链，而不是只给一段话
2. **引用可点开**：点击引用能看到原文档对应页的原文片段
3. **本体/图谱可视化**：让评委"看见"知识网，而不是听你描述

## 实现方式（三选一）
- **A（最快）**：拆解 Nexent 复刻出独立前端，调 Nexent 北向 API
- **B（最稳）**：Gradio / Streamlit 单页，本地起服务
- **C（最好看）**：Vue/React 前端 + 图可视化（Cytoscape.js / AntV G6）
